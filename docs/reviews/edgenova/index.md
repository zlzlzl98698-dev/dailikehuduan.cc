### 3. “多线路自动分配”概念解构

EdgeNova 在宣传中将“多线路自动分配”作为核心卖点。在网络工程实践中，这种架构通常有两种截然不同的实现方式：

1. **机制 A：智能 DNS / BGP Anycast 入口自动调度（真专线标准做法）**：
   用户本地只需要连接一个入口域名（如 `in.edgenova.net`），服务端根据用户发起连接的运营商（电信/联通/移动）和地理位置，通过 BGP Anycast 或 Anyhost 技术自动将请求调度到物理延迟最低的中继入口。这种方式用户体验极佳，能自动规避单点运营商拥塞，且完全支持标准的第三方通用订阅。
2. **机制 B：封闭客户端内部轮询（低成本伪自适应做法）**：
   品牌方不提供底层节点配置，而是强制用户下载其魔改客户端，客户端在后台定时对一系列便宜的直连 VPS 发起 ICMP Ping，哪台延迟低就连哪台。这种方式抗风险能力差，一旦遭遇晚高峰大面积丢包，客户端频繁重连会导致用户网络剧烈震荡。
