## 一、真实候选列表：合作权重与客观指标分离披露

在讨论任何“机场推荐”或“机场排行”之前，必须先解决信息透明度问题。一个负责任的选型页面不能把“编辑合作排序”包装成“科学实验室唯一冠军”，也不能隐瞒历史资料中的数据冲突与待核实项。

在本站数据库中，31 家去重品牌依据两套完全独立的维度进行记录：
1. **编辑精选优先级（含推广合作与资料完整度权重）**：反映品牌资料提交完整度、商业合作排列顺序（如 `#1 光速云`、`#2 暮光加速`、`#3 飞猫云` 等），并在页面中明确标注推广性质。
2. **客观技术与证据等级（`dataStatus`）**：严格区分 `measured`（明确标注时间、本地宽带、测试节点数的独立实测摘要）、`vendor`（品牌方资料或官方特性宣称，未独立复测）、`historical`（早期清单归档，缺乏当期套餐或协议细节）以及 `unknown`（资料缺失）。

## 三、不同人群适配方案：从设备与工作流反推选择

在代理生态里，没有“全能第一”的机场，只有“是否契合当前设备生态与流量习惯”的组合。选型前建议先通过 [客户端软件中心](/clients/) 确认工具链，再按以下六类典型使用场景匹配。

### 1. Windows / macOS 研发、文档检索与 AI 办公用户

这类用户的核心诉求是**低抖动、精细分流（国内外自动分流、Git/Docker/SSH 走直连或指定出口、AI 工具固定美/日/新出口）、可长期后台静默运行**。
- **推荐客户端**：Windows 首选 [Clash Verge Rev](/clients/clash-verge-rev/) 或 [v2rayN](/clients/v2rayn/)；macOS 首选 [Clash Verge Rev](/clients/clash-verge-rev/)、[Stash](/clients/stash/) 或 [Surge](/clients/surge/)，重度终端用户也可部署 [Mihomo](/clients/mihomo/) 或 [sing-box](/clients/sing-box/) 内核配合 TUN 模式。
- **机场筛选条件**：`clientMode` 必须为「第三方通用订阅」或「自研+第三方订阅」（例如 [光速云](/brands/guangsuyun/)、[一翻云](/brands/yifan/)、[可信云](/brands/kexin/)、[速界](/brands/sujie/)），绝对避开仅提供封闭客户端的品牌，否则无法写入自定义分流规则或处理 WSL/Docker 网桥冲突。关于虚拟网卡模式与 WSL 冲突处理，可参照 [TUN 模式与 WSL/Docker 冲突排查](/troubleshooting/tun-wsl-docker-conflict/)。

### 2. 零配置新手与纯移动端轻度查阅用户

不想理解 YAML 规则或订阅转换的新手，可选提供跨平台自研端或界面简洁的通用客户端（如 [FlClash](/clients/flclash/)、[Hiddify](/clients/hiddify/)、[Karing](/clients/karing/)）。可先在 [飞猫云](/brands/feimao/)、[Firefly](/brands/firefly/) 等专属端或 [光速云](/brands/guangsuyun/)、[梯子云](/brands/tiziyun/) 等双模式品牌中选 **¥20–¥25 月付入门档**试跑一月，但**首单切忌直接买年付**，双模式品牌日后迁移至软路由的成本也远低于纯专属端。流程详见 [新手如何选机场](/airport/beginner/)。

### 3. iOS / iPadOS 深度生态用户

iOS 需用外区 Apple ID 下载正版工具：性价比首选 [Shadowrocket](/clients/shadowrocket/)，Clash 规则同步可选 [Stash](/clients/stash/)，进阶规则重写可选 [Quantumult X](/clients/quantumult-x/) 或 [Surge](/clients/surge/)。**注意避坑**：多数仅专属端机场的 iOS 安装依赖企业签名或 TestFlight，存在掉签失效风险；选择支持通用订阅的品牌配合 App Store 正版软件，长期可靠性更高。详见 [iOS 平台客户端指南](/clients/platform/ios/)。

### 4. Android 与移动游戏低延迟用户

Android 推荐 [v2rayNG](/clients/v2rayng/)、[FlClash](/clients/flclash/)、[NekoBox](/clients/nekobox/) 与 [Hiddify](/clients/hiddify/)，详见 [Android 平台客户端指南](/clients/platform/android/)；手游 UDP 加速可结合 [游戏代理与低延迟指南](/vpn/gaming/) 与 [移动端 VPN 选型](/vpn/mobile/)。选机场时优先核实 UDP 转发及 Hysteria 2 / VLESS-Reality 等弱网协议支持（如 [一翻云](/brands/yifan/)），并测试 5G 与 Wi-Fi 切换断流恢复速度。

### 5. 多设备与家庭 OpenWrt 软路由统一接管

家庭电视（Apple TV / Android TV）、主机与 NAS 共享外网，推荐在 OpenWrt 旁路由或主路由部署 [OpenClash](/clients/openclash/)、[Nikki](/clients/nikki/)、[Passwall2](/clients/passwall2/) 或 [HomeProxy](/clients/homeproxy/)，详见 [OpenWrt 软路由部署指南](/clients/platform/openwrt/)。此类场景**必须选支持第三方通用订阅的品牌**并核对 1× 倍率，像 [飞猫云](/brands/feimao/)、[隐形人](/brands/yinxingren/)、[Firefly](/brands/firefly/) 等纯专属端均无法接入软路由。

### 6. 极低频刚需或第二备用通道用户

每月用量低于 5–15GB 或需要主力机场断网兜底时，优先购入 **¥99–¥147 的一次性不限时流量包**（如 [二猫云](/brands/ermao/) ¥99/100GB、[星岛梦](/brands/xingdaomeng/) ¥100/100GB、[唯兔云](/brands/weitu/) ¥100/100GB、[一翻云](/brands/yifan/) ¥100/100GB、[光速云](/brands/guangsuyun/) ¥147/247GB），且备用线应与主力采用不同协议或上游架构。详见 [不限时流量包指南](/plans/non-expiring/)。

## 四、靠谱机场的可验证判断指标

筛选靠谱服务应依靠买前或首月试错期即可自行核实的五项硬指标（详见 [靠谱机场判断指标](/airport/reliable/) 与 [选型避坑核查清单](/safety/avoid-scams/)）：

1. **协议与订阅透明度**：明确标注 VLESS-Reality、Trojan、Hysteria 2 或 Shadowsocks AEAD 协议，并写清是否输出通用订阅（如 [一翻云](/brands/yifan/)），或坦承仅用专属端（如 [飞猫云](/brands/feimao/)、[隐形人](/brands/yinxingren/)）；警惕鼓吹“自研黑科技加密”却回避导入方式的表述。
2. **资料冲突与缺口诚实度**：值得关注的是否掩盖短板。[可信云](/brands/kexin/) 主动声明缺乏 AI/流媒体统一实测，[光速云](/brands/guangsuyun/) 提示 ChatGPT/Gemini 需手动换节点，[灵动云](/brands/lingdong/) 实测摘要暴露 TikTok 失败与 YT 送中；相反，毫无实测依据却宣称“0 丢包、全永久解锁”的新站可信度较低。
3. **真实单价与倍率清晰度**：购前核对单月真实付款价、节点倍率（见 [线路倍率与流量计费](/routes/multipliers/)）及优惠码排除项，识别“大字标 ¥5.6/月、结账强制年付”或热门节点暗设 2×–5× 倍率扣费的套路。
4. **域名健康度与链接安全**：[云界线](/brands/yunjiexian/)、[榴莲云](/brands/liulianyun/)、[环球梯](/brands/huanqiuti/) 原始推广链接存在缺 `#/` 格式异常，[灵动云](/brands/lingdong/)、[浪网](/brands/langwang/)、[边缘节点 EdgeNova](/brands/edgenova/) 源自 2026-08-09 历史快照。遇 `linkAnomaly` 标记入口应先查 [品牌状态与链接核验](/brands/status/)，并在隔离账号下访问（参考 [隐私安全](/safety/privacy/) 与 [安全核验](/safety/security/)）。
5. **运营时长与止损意识**：2020–2023 年品牌（光速云、星岛梦、暮光加速、飞猫云、微风、二猫、唯兔）比 2025–2026 新品牌具备更长观察样本，但新老品牌均可能调整线路，故“首单月付 + 保留备用”永远成立。

## 五、稳定性与晚高峰对比方法（为什么不能只看测速图）

打开任何一家机场评测博客，你最常看到的就是一张绿油油的测速拼图：香港 22ms、529 Mbps，新加坡 45ms、413 Mbps。**把这种静态图直接当成稳定依据，是选机场最大的信息陷阱。**

### 1. 为什么 2026-10-19 历史测速汇总不等于你的实时体验

数据库前排多家品牌附带的 `2026-10-19` 摘要（港 21–27ms / 477–548 Mbps、台 37–41ms / 100–135 Mbps、新 42–46ms / 383–445 Mbps、日 53–57ms / 131–150 Mbps、美 134–180ms / 14–30 Mbps）均属**非晚高峰历史记录**，未标注测试省份、本地运营商与单/多线程口径，且不同脚本存在单位差异（如 [灵动云](/brands/lingdong/) 2026-07 珠海联通 9Gbps 实测为 `20–80 MB/s`，按 `1 MB/s = 8 Mbps` 换算约 160–640 Mbps）。历史快照无法替代当前晚高峰负载测验。

### 2. 晚高峰 20:00–23:30 四步可复现自测法

首月试用请在 20:00–23:30 连续三天于本地宽带执行核验（详见 [晚高峰稳定性测试](/airport/stable/) 与 [延迟与测速换算](/routes/latency/)）：

1. **测 TLS/HTTP TTFB 而非只看列表 Ping**：客户端列表的延迟测试多为单次 HEAD 耗时；在本地代理端口（如 `127.0.0.1:7897`）下连续运行 5 次请求，亚洲节点晚高峰理想 TTFB 应稳在 `0.15s–0.45s`：
   ```powershell
   1..5 | ForEach-Object {
     curl.exe -x http://127.0.0.1:7897 -o NUL -s -w "Run $_ | TCP:%{time_connect}s | TLS:%{time_appconnect}s | TTFB:%{time_starttransfer}s | Total:%{time_total}s`n" https://www.google.com/generate_204
   }
   ```
2. **测单线程稳定性**：关闭多线程下载插件，观察 YouTube 4K60fps“详细统计信息”里的 `Connection Speed` 是否平稳保持在 30,000 Kbps 以上且不周期性跌零。
3. **长连接防断流检查**：不要用 ICMP Ping 代理端口，应通过 TUN 模式或持续 SSH/HTTPS 长连接观察夜间是否频繁重连。
4. **分地区节点抽样**：从港/日/新/美各抽 3 个节点测试连通率，排查类似早期实测中出现的单节点整区失败。

### 3. 国内三网运营商与协议弱网抗性差异

电信 163 民用宽带晚高峰跨网拥堵最突出，联通国际出口相对平稳但跨网单线易抖动，移动（CMI）部分地区对高并发 UDP 存在 QoS 限速。在协议层面，基于 QUIC（UDP）的 **Hysteria 2** 在轻度丢包弱网下重传恢复极快，但若遇本地 UDP 限速会大幅降速；**VLESS-Reality** 与 **Trojan** 走 TCP/TLS 抗运营商 UDP 压制更稳。因此支持多协议并存的通用订阅（如同时含 Hysteria 2 与 VLESS-Reality）在跨网排障时更具弹性。

为避免用户误读站内各品牌详情页展示的测速数值，下表汇总数据库中三类不同证据等级的测速记录形态及其适用限度：

## 七、IEPL / IPLC / 普通中转差异：看懂线路术语

几乎每家机场的介绍页都会出现“IEPL 专线”、“IPLC 专线”、“BGP 智能调度”或“隧道中转”字样。理解这些术语的真实工程意义，能帮你识别哪些宣传有物理支撑，哪些属于过度包装。深入拓扑拆解见 [线路科普中心](/routes/)、[IEPL 专线详解](/routes/iepl/) 与 [IPLC 国际专线科普](/routes/iplc/)。

1. **公网直连（Direct）**：本地宽带直接把加密代理数据包发往海外 VPS。遇到晚高峰国际出口拥堵或 GFW 深度包检测（DPI）针对性干扰时，极易出现延迟暴涨、断流甚至端口阻断。目前正规中高端商业机场较少采用纯公网直连作为主力。
2. **隧道中转（Tunnel / 公网中转）**：你的设备先连接国内机房（如广州、深圳、上海、北京 BGP 节点），由国内中转机封装后通过公网或优化骨干路由转发至香港/海外落地机。优势在于国内三网到中转入口延迟低、协议隐蔽性更强；弱点是**中转机到境外落地机之间依然经过公网国际出口**，极端高峰期或特定波动期仍可能丢包。
3. **IPLC（International Private Leased Circuit，国际专线租用线）**：通过运营商点对点物理或二层专线跨越边境（例如深港 IPLC、沪日 IPLC），数据在跨境段不经过公网防火墙检测路径。最大价值在于**大幅降低跨境段丢包率与阻断概率**，即便在特殊时期也能保持较高连通率。
4. **IEPL（International Ethernet Private Line，国际以太网专线）**：基于以太网协议的跨境专线，相比传统 IPLC 具有更灵活的带宽切分与多点组网能力，是目前商业机场最主流的高稳定专线方案。

**选型必看的三个误区提醒**：
- **专线不等于突破光速物理延迟**：哪怕用上顶级 IEPL/IPLC，从北京到美国西海岸的物理光纤往返时延依然在 130ms–180ms 左右；专线优化的是**抖动（Jitter）与丢包率（Packet Loss）**，而不是让美国节点变成 20ms。
- **注意同一品牌内的线路口径混用**：在本站数据库核验中，[光速云](/brands/guangsuyun/) 的不同文档曾分别出现“IEPL+企业内网”、“IPLC+隧道中转”与“全 IPLC”三种说法；[宇宙云](/brands/yuzhou/) 汇总表与正文也存在“三网优化”与“IEPL”字段串行。遇到类似情况，应以实际晚高峰丢包率为准，而不要纠结营销话术名称。
- **落地机与出口倍率同样关键**：专线成本按带宽和流量双向计费，部分低价套餐即便标注 IEPL，也可能在部分热门线路使用 2×–5× 倍率，或在高峰期对单用户进行限速，以确保总体专线账单不亏损。

## 八、节点地区与使用需求匹配

节点不是“国家越多越好”，而是看你的常用服务集中在哪些地区，以及落地 IP 的类型（机房数据中心 IP、广播 IP 还是原生住宅 IP）。

- **香港节点（历史非晚高峰参考延迟约 21–27ms）**：适合日常网页检索、GitHub/npm/Docker 拉取、中文社区访问与追求极低交互延迟的办公场景。**注意边界**：OpenAI ChatGPT、Anthropic Claude 等主流 AI 平台通常**不支持香港地区 IP**，部分台湾/大陆以外流媒体版权库也与美日不同。详见 [香港线路延迟与定位](/routes/hong-kong/)。
- **日本节点（历史非晚高峰参考延迟约 53–57ms）**：兼顾亚太较低延迟与较强的 AI/流媒体兼容性（东京/大阪区域广泛支持 ChatGPT、Netflix 日区动画库及日服游戏）。缺点是晚高峰（尤其部分家用宽带到日本路由）容易出现波动，且免费或低价机房 IP 常被 Google 搜索弹出人机验证码。详见 [日本线路延迟与选型](/routes/japan/)。
- **新加坡节点（历史非晚高峰参考延迟约 42–46ms）**：东南亚核心枢纽，通常对 ChatGPT、Claude 较为友好，也是华南地区延迟表现优秀的替代出口。但需注意部分广播 IP 段容易触发 YouTube“送中”（定位被误判为中国大陆导致无法开启后台播放或屏蔽特定内容）或流媒体地区错配。
- **台湾节点（历史非晚高峰参考延迟约 37–41ms）**：繁体中文内容、巴哈姆特动画疯等区域流媒体以及部分亚太服务的核心节点。需防范落地 IP 被流媒体识别为欧洲或其他地区（例如 [灵动云](/brands/lingdong/) 2026-07 实测中出现台湾节点 Netflix/Disney+ 识别为西班牙 ES 且 YouTube 送中的案例）。
- **美国节点（历史非晚高峰参考延迟约 134–180ms）**：AI 服务（ChatGPT、Claude、Gemini）、美区流媒体（Netflix 完整美区片库、HBO Max、Hulu）与美区电商/开发工具的绝对主力。由于跨太平洋物理距离远，下载单线程速率通常明显低于港新日节点（历史摘要多在 14–30 Mbps 区间），日常刷网页不建议默认全局挂美国节点。
- **韩国、欧洲与小众地区**：如果你需要韩服游戏、欧区电商、土耳其/阿根廷低价区订阅或 TikTok 特定国家运营，需要提前核实品牌是否提供对应区域（例如 [星岛梦](/brands/xingdaomeng/) 标注覆盖韩国与东南亚，[光速云](/brands/guangsuyun/) 地区标签含英/法/德/土/泰/巴，[SOGO 云](/brands/sogo/) 宣称覆盖 15 个国家和地区），并向客服或实测确认并非“挂名伪节点”。

## 九、AI 与流媒体兼容性边界（为什么“全解锁”不可盲信）

在 31 家品牌数据库的原始材料中，绝大多数商家都会在特性表里把 ChatGPT、Claude、Netflix、Disney+、YouTube 全部打上“支持”标签。但从网络工程现实来看，**IP 解锁与 AI 风控是动态对抗过程，没有任何机场能够保证永久免风控。**

1. **区分证据等级：`confirmed` vs `vendor` vs `conditional` vs `failed`**：
   本站品牌详情页把 AI 与流媒体状态严格分为品牌资料宣称（`vendor`）、条件支持（`conditional`）、实测确认（`confirmed`）和实测失败（`failed`）。目前绝大多数品牌处于 `vendor` 状态——即商家标注支持，但未附第三方连续测验报告。
2. **主流 AI 平台的风控痛点**：
   - **ChatGPT**：对数据中心共享 IP 极其敏感。共享节点上同时有上百人高频调用网页端或触发风控操作时，极易出现 `Access denied`、无限 Cloudflare 人机验证或降级模型提示。即使是编辑精选首位的 [光速云](/brands/guangsuyun/)，其官方资料也坦承 ChatGPT/Gemini 并非所有节点稳定，需要手动切换节点；详细排查见 [ChatGPT 节点风控与解锁指南](/ai-streaming/chatgpt/)。
   - **Claude**：风控比 OpenAI 更严格，高频出现封号或地区不支持提示，不仅看 IP 归属地，也看 ASN 属性（家宽/住宅 IP 远比普通云厂商 IP 稳定）。[二猫云](/brands/ermao/) 等品牌在数据库即标注为 `conditional`；分流与降封风险策略见 [Claude 地区限制与排查](/ai-streaming/claude/)。
   - **Gemini**：对 IP 清洁度与 Google 账号关联地区要求高，部分欧洲或亚洲广播 IP 会跳转至受限页面或拒绝访问；配置指南见 [Gemini 节点与分流规则](/ai-streaming/gemini/)。
3. **流媒体解锁常见坑点**：
   - **Netflix 自制剧 vs 全解锁**：很多机场宣称“解锁 Netflix”，但仅能播放 Netflix 自制剧（Originals），非自制版权剧集直接提示代理检测或地区不可用。见 [Netflix 解锁核验标准](/ai-streaming/netflix/)。
   - **YouTube 送中与地区漂移**：由于某些低成本落地服务器使用了曾经关联中国大陆路由信息的广播 IP，Google 会把 YouTube 定位错误归入大陆地区，导致账号记录异常或无法看特定内容。见 [YouTube 送中现象排查](/ai-streaming/youtube/) 与 [Disney+ 解锁说明](/ai-streaming/disney/)。
4. **客户端分流与 DNS 防泄漏是解决兼容性的必需手段**：
   不要把所有流量都放在同一个美国或香港节点上。正确的做法是在支持规则分流的客户端（如 Clash Verge Rev、Mihomo、sing-box、Shadowrocket）中，编写独立的策略组：日常网页与下载走低延迟香港/日本组，OpenAI/Claude/Gemini 单独指向经过验证的美/日/新纯净出口组，国内直连规则走 `DIRECT`。同时需留意本地系统的 **IPv6 泄漏与浏览器安全 DNS（DoH）绕过代理**：如果浏览器开启了自定义 DoH 且没有被代理软件接管，或者本地宽带分配了公网 IPv6 地址而客户端规则未拦截或接管 IPv6 出站，目标流媒体与 AI 站点会直接检测到国内真实 DNS 解析链路或拒绝服务。配置教学见 [分流规则配置教程](/guides/routing/)、[TUN 模式部署指南](/guides/tun/) 与 [Clash 配置结构详解](/guides/clash-config/)。

| 业务需求类型 | 核心核验指标 | 数据库高频踩坑点 | 推荐分流策略与替代路径 |
| :--- | :--- | :--- | :--- |
| **ChatGPT / API 调用** | 落地 IP 清洁度、是否避开香港地区、Cloudflare 验证频率 | 光速云明确提示非全节点稳定；共享高负载免费/低价节点易触发频繁验证 | 单独划分 `AI-Group` 策略组指向美国/日本/新加坡低负载节点，固定单一地区减少 IP 频繁横跳 |
| **Claude 网页与代码助手** | 原生或低风控 ASN 归属地、会话 IP 一致性 | 隐形人/二猫云等仅部分条件支持，非纯净机房 IP 易触发账号风控封号 | 严禁开启“自动最低延迟频繁切节点”，为 Claude 绑定固定静态落地节点 |
| **Netflix / Disney+ 4K** | 非自制剧全解锁状态、版权区识别一致性 | 灵动云 2026-07 实测曾出现台湾节点被识别为西班牙（ES）的地区错配 | 使用支持多区节点切换的通用订阅，按所需片库（美区/港区/台区/日区）手动锁定出口 |
| **YouTube / TikTok 运营** | 是否发生“送中”、移动端 UDP/TCP 连通与地区合规性 | 灵动云历史实测暴露新/台 YT 送中与 TikTok 多节点失败；部分机场不支持外区直播推流 | TikTok 运营等高敏业务谨慎评估共享机场，必要时查阅品牌独享原生 IP 定制条款并核实归属 |

## 十、客户端与多设备支持：专属端 vs 通用订阅的长期代价

客户端接入模式（`clientMode`）直接决定了你的设备自由度、安全可控性与未来迁移成本。在本站 31 家品牌中，可以清晰划分为三种架构阵营：

### 1. 第三方通用订阅 / 双模式阵营（高自由度推荐）

- **代表品牌**：[一翻云](/brands/yifan/)、[可信云](/brands/kexin/)（纯通用订阅）；[光速云](/brands/guangsuyun/)、[梯子云](/brands/tiziyun/)、[速界](/brands/sujie/)、[极连云](/brands/jilian/)、[光年梯](/brands/guangnian/)、[大佬云](/brands/dalaoyun/)、[闪电鼠](/brands/shandianshu/)、[神行加速](/brands/shenxing/)（自研+第三方双支持）。
- **核心优势**：获取标准订阅 URL 后，可在 [Windows](/clients/platform/windows/)（Clash Verge Rev / v2rayN / FlClash）、[macOS](/clients/platform/macos/)（Clash Verge Rev / Stash / Surge）、[iOS](/clients/platform/ios/)（Shadowrocket / Stash / Quantumult X）、[Android](/clients/platform/android/)（v2rayNG / NekoBox / Hiddify）、[Linux](/clients/platform/linux/)（Mihomo / sing-box CLI）以及 [OpenWrt 软路由](/clients/platform/openwrt/)（OpenClash / Nikki / Passwall2 / HomeProxy）之间无缝切换。即便同时订阅两家机场，也能在同一个客户端内合并策略组做故障自动切换（Fallback）。订阅格式差异与导入排错见 [订阅管理与导入指南](/guides/subscription/)、[订阅格式深度解析](/guides/subscription-formats-explained/) 与 [订阅更新失败排查](/troubleshooting/subscription/)。

### 2. 仅专属客户端阵营（零配置但强锁定）

- **代表品牌**：[飞猫云](/brands/feimao/)、[隐形人](/brands/yinxingren/)、[SOGO 云](/brands/sogo/)、[闪跃](/brands/shanyue/)、[全球云](/brands/quanqiu/)、[灵猫网络](/brands/lingmao/)、[Firefly](/brands/firefly/)（2026-10 起停发订阅链接），以及正文存在转型记录的 [无忧链接](/brands/wuyou/)。
- **核心优势与代价**：优势是省去订阅链接获取、节点更新与规则配置步骤，适合完全不懂技术的纯新手；但代价同样沉重——**无法导入任何开源审计过的第三方客户端，无法自定义分流规则，无法接入 OpenWrt 软路由或 NAS，iOS 端还可能受限于非 App Store 分发渠道**。购买这类品牌前，务必确认自己未来半年到一年内没有换用软路由或自定义 AI 分流的打算。

### 3. “不限设备数”与多设备并发的真实逻辑

数据库中有超过十家品牌标注“不限设备数”（如光速云、星岛梦、二猫云、无忧链接、唯兔云、Firefly、U1S1、灵猫网络、一翻云、灵动云）。但从技术风控角度，用户必须理解两个事实：
1. **“不限设备”通常不等于允许公网多人合租**：如果同一个订阅在短时间内从国内五六个不同省市的宽带或移动 IP 同时发起高频连接，机场审计系统依然会判定为异常泄露或恶意转卖而临时封禁订阅链接。
2. **家庭多设备最佳实践是软路由网关收敛**：在家庭局域网内，将 1 台运行 [OpenClash](/clients/openclash/) 或 [Nikki](/clients/nikki/) 的软路由作为代理出口，家里手机、电视、电脑、NAS 全部通过局域网网关出站，在机场服务端看来往往只体现为单一口径的宽带公网 IP（除非同时启用了移动蜂窝网络），既免去逐台设备配置同步订阅的麻烦，也能大幅降低并发风控风险。具体拓扑部署见 [多设备与家庭方案](/airport/multi-device/)。

### 4. 客户端内核选择、订阅安全与主备容灾

- **Mihomo vs sing-box 内核**：[Clash Verge Rev](/clients/clash-verge-rev/)、[FlClash](/clients/flclash/)、[OpenClash](/clients/openclash/)、[Nikki](/clients/nikki/) 基于 [Mihomo](/clients/mihomo/) 内核，规则生态成熟；[Hiddify](/clients/hiddify/)、[Karing](/clients/karing/)、[NekoBox](/clients/nekobox/)、[Passwall2](/clients/passwall2/)、[HomeProxy](/clients/homeproxy/) 基于 [sing-box](/clients/sing-box/) 内核，内存占用与新协议统一性表现好；[v2rayN](/clients/v2rayn/) 支持多核心切换。
- **防范订阅泄露**：订阅 URL 含个人鉴权 Token，切勿粘贴到来路不明的在线订阅转换网站；应使用客户端内置转换或本地 Docker 自建后端。定时更新方法见 [自动更新配置教程](/guides/automatic-update/)。
- **主备自动切换**：在同一 Clash/Mihomo 配置中通过 `proxy-providers` 接入主力月付机场与备用不限时流量包，将常用业务指向 `type: fallback` 组，主力超时数秒内自动切往备用线。

## 十一、月付 / 年付 / 不限时注意事项

付款周期的选择，本质上是**折扣收益与平台运营风险之间的资金博弈**。

1. **为什么首单必须坚持月付**：无论商家客服如何承诺、优惠码打几折，首次接触一家从未在本地宽带测试过的机场，**首单周期只应买 1 个月**。控制单次最高试错资金在 ¥14.9–¥25（参考 [月付机场推荐原则](/plans/monthly/)），就算线路不合本地运营商胃口、晚高峰炸裂或者次周失联，损失完全可控。
2. **算清“年付折算月均”背后的沉没成本**：在 [性价比机场价格比较](/plans/value/) 中可以看到，¥79/年、¥84/年、¥99/年 把月均摊低到了 ¥6.58–¥8.25，确实极具吸引力。但前提是两件事必须同时成立：**第一，你已经在单月套餐中验证过它对你家宽带稳定可用；第二，你每月确实能消耗 40GB–70GB 左右流量且不常出现爆发式超标**。另外要注意优惠码排除规则——例如 [光速云](/brands/guangsuyun/) 的 ¥99 年付轻量版与 147 永久版、[Firefly](/brands/firefly/) 的 ¥96 年付版、[闪跃](/brands/shanyue/) 的 ¥96 年付版以及 [灵猫网络](/brands/lingmao/) 的 ¥85 年付小包，均在原始资料中明确注明**不参与常规 8 折新人码**。详情见 [套餐优惠与优惠码核验](/brands/coupons/)。
3. **一次性不限时流量包的正确打开方式**：不限时流量包（如 ¥99–¥147/100GB–247GB）最大的优点是没有“月底清零焦虑”，最适合作为**主力的灾难冗余备用**或**每月用量低于 15GB 的轻度刚需**。但切忌一次性花费 ¥500–¥1,199 购买 500GB–1TB 的巨额不限时包——流量不过期的前提是服务商本身一直在线运营，把大额预付款长期押在单一机场不符合风险分散原则。

## 十二、品牌风险与售后说明

在选购前，请务必对照以下四类常见运营风险与售后边界核查清单一一过筛（延伸阅读：[机场关停风险分析](/safety/closures/)、[退款与争议边界](/safety/refunds/)、[备用替代方案原则](/safety/alternatives/)、[同类品牌替代检索](/brands/alternatives/)）：

2. **“7×24 客服”与“夜间 AI 值守”的差异**：多家品牌（如微风网络、Firefly）明确标注夜间时段由 AI 自动值守客服。遇到订阅拉取失败、节点大规模维护或支付未到账问题时，工单系统往往比即时聊天框更有效；同时请先用 [故障排查向导](/troubleshooting/) 与 [超时断联排查](/troubleshooting/timeout/)、[DNS 污染排查](/troubleshooting/dns/) 自检本地系统时间与代理设置（系统时间误差超过 90 秒会直接导致 TLS/VLESS/Trojan 握手失败，处理方法见 [系统时间与 TLS 修复教程](/guides/system-time-tls-fix/)）。
3. **新品牌与同系模板重合现象**：数据库显示，2025–2026 年成立了较多新品牌，同时部分低价档（如 5.6 元档 5 家、以及部分套餐命名与价格结构高度接近的品牌组）存在推广页面与套餐结构高度雷同的现象，部分品牌之间（如 Firefly 历史资料提及与微风等存在同系关联）可能共享上游或技术团队。分散准备备用机场时，**不要把主用和备用买在同一个技术模板或同一个关联矩阵之下**，否则上游线路出现波动时主备会同时失效。
4. **注意链接异常与历史档案数据时效**：2026-08-09 历史扩展条目（灵动云、浪网、边缘节点）以及 URL 存在格式异常的品牌（云界线、榴莲云、环球梯）在进入注册页前须核验当前可达性与价格变更，避免按过时截图下单。
5. **从注册支付到断连排查的风险隔离工作流**：
   - **账号与支付隔离**：在注册机场面板时使用独立电子邮箱别名和随机高强度密码，避免与微信、支付宝或常用邮箱密码重复；支付前先核实面板实际支持的渠道（例如 [Firefly](/brands/firefly/) 历史资料标注仅支持支付宝与 USDT、无微信支付，[灵动云](/brands/lingdong/) 历史资料注微信支付需联系客服）。若采用 USDT 等链上支付，需提前核算对应网络手续费，避免小额 ¥20 套餐因链路矿工费产生额外隐性溢价。
   - **先查本地环境再判定节点故障**：购买后若出现客户端无法连接、节点全超时或订阅拉取报错，不要急于在群组刷屏或直接重购，应按“本地系统时间校准 → 代理端口与浏览器扩展冲突检查 → TUN 模式路由冲突排查 → 订阅链接可达性测试”顺序定位。Windows/macOS 本机时间与标准 UTC 时间偏差超过 90 秒会导致 VLESS/Trojan TLS 握手直接被服务端拒绝，可参考 [系统时间与 TLS 修复教程](/guides/system-time-tls-fix/)、[客户端启动与端口报错](/troubleshooting/startup/)、[已连接但无法上网断流排查](/troubleshooting/disconnected/) 以及 [TUN 模式基础排错](/troubleshooting/tun/) 逐项排除。

## 十三、常见选择错误清单（买前必看）

1. **错误一：把“年付折算月价”当成“月付入门价”**。看见海报写“最低 5.6 元/月”或“8 元/月”，点进去才发现必须一次性付 ¥67–¥99 买整年，真正只买单月要 ¥19–¥25。
2. **错误二：先付钱买机场，后发现是“仅专属客户端”**。买完才想起来自己主力设备是 OpenWrt 软路由、iOS Shadowrocket 或 macOS Surge，结果商家压根不给订阅链接，钱退不了也用不上。
3. **错误三：盲信非晚高峰测速截图**。看到别人白天测出 500 Mbps 就以为晚高峰稳如本地光纤，没有在自家宽带的 20:00–23:30 亲自测单线程 TTFB 和 4K 缓冲曲线。
4. **错误四：只看标称流量 GB，不问节点倍率**。买了 150GB/月 的套餐，日常全连着标注 `2×` 或 `3×` 的优化节点，实际只用了 50GB–75GB 就提前耗尽流量。
5. **错误五：为图省事或单价低，首单囤积三年付或千元大额不限时包**。忽视行业天然存在的域名变更、上游清退与运营变动风险，把原本可控的 ¥25 试错成本放大到上千元不可挽回敞口。
6. **错误六：在多个未知安全性的新机场用同一个主邮箱和主密码注册**。一旦某个低价小站发生数据库泄露或撞库，容易波及其他常用账户；注册机场面板应坚持**独立邮箱别名 + 随机独立密码**。
7. **错误七：开启代理后仍无法打开 AI 或流媒体，却忽略浏览器 DoH 与系统时间校准**。很多用户误以为刚买的机场“全节点失效”，实际是因为电脑本地系统时间偏差导致 TLS 握手拒绝，或 Chrome/Edge 开启了内置安全 DNS 绕过了 Clash 分流规则。
8. **错误八：把特定档位的优惠码当成全场通用折扣**。下单前未看清排除条款（例如光速云轻量版/147 永久版、Firefly 年付版、闪跃年付版、灵猫年付小包均明确不适用常规 8 折码），导致结账金额与预期不符。

## 十四、机场 vs 商业一体式 VPN 的适用边界与 6 步上车核对清单

不少初学者会在“买代理机场配合开源客户端”和“买海外商业一体式 VPN 软件”之间犹豫。两者在网络架构、国内适配度、分流精度与适用场景上存在显著差异，合理区隔能避免花冤枉钱（详细横评见 [VPN 推荐总览](/vpn/recommend/)、[商业 VPN 对比](/vpn/compare/) 与 [免费 VPN 风险警示](/vpn/free/)）：

| 比较维度 | 代理机场 + 开源通用客户端（Clash / Shadowrocket 等） | 海外商业一体式 VPN（Express/Nord/Surfshark 等模式） |
| :--- | :--- | :--- |
| **跨境协议与抗干扰** | 采用针对复杂网络环境演进的 VLESS-Reality、Trojan、Hysteria 2 或 IEPL/IPLC 专线中转 | 多采用传统 OpenVPN、WireGuard 或自研混淆协议，国内直连高干扰期易大面积阻断 |
| **国内分流精度** | 极高。内置 `geosite:cn` / `geoip:cn` 规则，国内网银、淘宝、游戏自动直连不降速 | 较弱或仅粗粒度应用白名单，常出现国内 App 变慢或误走国外出口 |
| **晚高峰体验上限** | 优质专线中转节点在晚高峰可保持较低香港/日本延迟与高单线程吞吐 | 国内直连海外节点延迟高且晚高峰丢包严重，通常需二次中转才可用 |
| **隐私与审计属性** | 开源客户端透明可控，但机场运营主体与日志策略需谨慎评估，避免用主邮箱注册 | 部分大型海外商业 VPN 具备独立第三方无日志审计报告与明确法律实体 |
| **适用人群建议** | 长期在国内生活办公、需要国内外智能分流、追求低延迟与 AI/流媒体灵活切换的用户 | 身处海外需要加密公共 Wi-Fi、或对特定国际企业合规日志审计有刚需的用户 |

### 从零开始购前到验证的 6 步实操核对清单

1. **安装客户端**：Windows/macOS 参考 [客户端安装标准流程](/guides/installation/) 与 [Clash Verge Rev 配置教程](/guides/clash-verge-rev-setup/)，iOS 确认外区 Apple ID 就绪 Shadowrocket 或 Stash。
2. **筛选主备候选**：在 [品牌数据库检索中心](/brands/directory/) 按“支持通用订阅 + 单月 ≤ ¥25 + 协议明确”选出 1 主 1 备，同时核对是否存在 `linkAnomaly` 链接异常。
3. **隔离注册与核价**：用独立别名邮箱注册，结账前核对是否为 1 个月周期、支付渠道手续费及优惠码是否排除了当前档位。
4. **导入订阅与分流**：导入后开启规则分流（国内外自动分流），避免长期全局代理消耗无效流量。
5. **晚高峰三天抽检**：在 20:00–23:30 用 `curl.exe` TTFB 与单线程缓冲测试港/日/新/美节点，同时核对面板流量扣减是否吻合 1× 倍率。
6. **补充低成本容灾备份**：确认主力达标后，可加配 ¥99–¥108/100GB 不限时流量包写入 `fallback` 自动切换组。

## 十五、常见问题（FAQ）

### 选机场前为什么建议先确定自己要用的代理客户端？

在本站收录的 31 家品牌中，部分机场仅提供自研专属客户端，不输出 Clash YAML、Mihomo、sing-box 或 Base64 通用订阅。如果你依赖 Clash Verge Rev、Shadowrocket、Surge 或 OpenWrt 软路由分流规则，先买机场后发现不支持第三方订阅会导致无法接入或被迫更换整套使用习惯。

### 本站机场推荐和 31 家品牌库的排序依据是什么？

本站默认展示的「编辑精选」顺序（如 [光速云](/brands/guangsuyun/) #1、[暮光加速](/brands/muguang/) #2、[飞猫云](/brands/feimao/) #3）包含推广合作优先级与资料完整度权重，并非实时测速排行榜。如需按真实月付门槛、协议类型或客户端模式筛选，请前往 [品牌数据库检索中心](/brands/directory/) 使用条件过滤，不要把合作排序当作实时网速排名。

### 新手第一次购买机场怎样把试错成本和风险降到最低？

优先选择支持第三方通用订阅且明确标出协议的品牌，首单只买一个月期套餐（通常在 ¥14.9–¥25 区间），在同一地区节点中对比 20:00–23:30 晚高峰单线程可用性与网页首字节延迟，稳定运行满 30 天后再决定是否续费或考虑季度/年度周期。

### 宣传页写的“最低 5.6 元/月”或“8 元/月”能按这个价格只买一个月吗？

绝大多数情况下不能。这类数字属于“年付总价除以 12”的折算月均价（例如 ¥99/年 折算 ¥8.25/月、¥84/年 折算 ¥7.00/月、¥79/年 折算 ¥6.58/月，5.6 元档同样是年付折算参考价），真正支持单月购买的入门门槛通常在 ¥14.9–¥25/月。详见 [价格与套餐指南总览](/plans/)。

### 非晚高峰测速跑到 500 Mbps，为什么晚高峰看 4K 视频或拉取代码还是卡顿？

国际出口拥堵集中在 20:00–23:30 本地晚高峰时段。非晚高峰测速（包括本库收录的 2026-10-19 历史非晚高峰摘要）反映的是空闲带宽上限，无法体现跨境入口在晚高峰的丢包率、TCP 重传与单线程限速情况，因此必须以晚高峰单线程实测为准。

### 宣传写着“IEPL 专线”或“IPLC 专线”就一定不会断流或高延迟吗？

不一定。IEPL 与 IPLC 主要优化境内入口到境外出海口这一段跨境传输的丢包与干扰问题，但落地机房质量、节点超售比例、本地运营商到国内入口之间的路由拥堵，以及多品牌资料中同一家混写 IEPL/IPLC/隧道中转的口径差异，都会直接影响实际延迟与稳定性。

### 为了使用 ChatGPT、Claude 和 Netflix，选节点地区时要注意什么？

不要只看总带宽，必须区分地区政策与落地 IP 风控。OpenAI 与 Anthropic 对部分香港节点和机房 IP 存在封锁或高频验证，部分地区（如灵动云 2026-07 历史实测中的台湾与新加坡节点）还会出现 YouTube 送中或流媒体地区识别偏移，需结合实际节点分流策略手动切换。

### 机场宣传“不限设备数”就代表可以无限分享给家人朋友吗？

通常并非字面意义上的无限制。虽然光速云、星岛梦、二猫云、无忧链接等品牌资料标注“不限设备”，但机场后台仍会监控异常高频的并发源 IP 数量与短时间跨省市跳变；家庭多设备共享更稳妥的方式是在 OpenWrt 软路由上运行 [OpenClash](/clients/openclash/) 或 [Nikki](/clients/nikki/) 进行单出口网关转发。

### 为什么部分品牌资料里标注了 59GB/69GB 冲突或优惠码不一致？

品牌方在不同时期或不同推广渠道发布的套餐简报、详表与历史归档截图常出现口径滞后。本站坚持保留并如实披露这些矛盾（如光速云 59GB 与 69GB 差异、暮光加速优惠码文本矛盾、二猫云新加坡节点文本与测速表冲突），提醒用户在结账页以实时显示为准。

### 如果机场跑路、域名打不开或买错专属客户端套餐怎么办？

多数机场在服务条款中注明虚拟服务不支持无理由退款，因此首单严格控制在单月小额以内最为关键。若遇到原域名失效或链接异常，应先通过 [品牌状态与链接核验](/brands/status/) 及 [故障排查向导](/troubleshooting/) 排查是否为客户端缓存、DNS 污染或域名更换，并准备低成本备用订阅方案分散单点失效风险。
