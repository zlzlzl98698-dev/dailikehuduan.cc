## 一、平台使命与核心价值观

跨国加密中继与科学上网技术是现代科研人员、跨境电商、软件工程师及跨文化内容创作者必不可少的基础生产力工具。然而，当前的中文互联网环境长期充斥着大量缺乏技术依据的测评排行榜、充值返利挂机站以及信息滞后的跑路黑产。

本站设立三大基石使命：
1. **开源至上与工具中立**：优先指导用户掌握开源跨平台内核（Mihomo / Clash.Meta、Sing-box、Xray）的配置与分流逻辑，推荐去中心化的通用订阅，反对强行捆绑私有客户端的锁定行为。
2. **拒绝滤镜与工程实证**：每一次测速必须标明测试时间戳、运营商环境（电信/联通/移动）、线程数与单线程吞吐，杜绝非晚高峰局域网内网跑分冒充实际体验。
3. **保护用户资金底线**：针对行业内普遍存在的“年付大额折扣随后关站”现象，在全站所有套餐推荐中常态化提示“首单仅买单月（不超25元）、严禁盲目大额年付”。

## 三、五级数据置信度体系（Evidence-Based Methodology）

为彻底解决“厂商自说自话、评测真假难辨”的行业顽疾，本站对全量 31 家机场品牌库的全部字段实行分级审计：

| 证据级别代码 | 级别名称 | 判定标准与采信准则 | 在本站前端的具体呈现形式 |
| :--- | :--- | :--- | :--- |
| **`verified`** | **已核实结构事实** | 经代码级多源比对、官网面板结构验证无误的客观元数据 | 绿色徽章；如品牌 Slug、支付方式、后台真实包含的套餐档位 |
| **`measured`** | **明确条件独立实测** | 标明明确测试日期、ISP 网络环境、单线程/多线程与丢包率的实测采样 | 蓝色徽章；如 2026-08-19 跨网 MiaoKo 原始跑分长图 |
| **`vendor`** | **品牌方公开宣称** | 仅有官方文案宣传、未经独立第三方晚高峰验证的承诺性声明 | 橙色徽章；如“全物理专线”、“原生双ISP住宅IP”、“全流媒体解锁” |
| **`historical`** | **历史归档记录** | 源自历史留存清单或旧版快照，随时间推移可能发生变更的数据 | 紫色徽章；明确标注快照采集日期，提示用户以最新面板弹窗为准 |
| **`unverified`** | **待核实核心指标** | 原始资料未明确披露、关乎日常体验的关键参数 | 灰色徽章；如专属客户端是否放开订阅导出、晚高峰真实丢包 |
| **`conflicted`** | **逻辑冲突与数据异常** | 资料内部存在自相矛盾、定价倒挂或截图遮挡的问题 | 红色强警示徽章；设立公开台账并在评测正文顶部如实公布 |

## 四、商业化合规与推广透明度声明（Affiliate Disclosure）

本站奉行完全阳光透明的商业化准则：

1. **推广链接属性规范**：
   全站所有通往第三方机场服务商的注册跳转链接，**一律通过受控组件输出，并强制附加 `target="_blank" rel="nofollow sponsored noopener noreferrer"`**。本站绝不采用隐蔽的重定向劫持或暗度陈仓的内嵌跟踪代码。
2. **佣金与评测分离原则**：
   我们可能会从部分品牌的用户注册中获得微额的推广返利以贴补服务器托管成本。但**佣金比例绝不决定品牌排序、绝不影响评测星级、绝不换取掩盖数据冲突的特权**。
3. **退款红线强制披露**：
   对于在服务条款中明确声明“虚拟商品概不退款”的服务商，本站绝不粉饰，必须在显著位置提醒读者承担相应的试错风险。

## 五、用户隐私保护与零追踪承诺

- **零第三方追踪**：全站未嵌入任何 Google Analytics (GA4)、百度统计、各类广告联盟追踪像素（Pixel）或第三方 Cookie；
- **全站纯静态交付**：文档基于 VitePress 生成纯静态 HTML，在宿主服务器上仅记录最基本的 Web 服务器访问日志（严格用于抵御 DDoS 攻击与安全审计，不与任何商业广告平台共享数据）；
- **免责声明**：本站所介绍之网络代理客户端与开源工具，仅供技术研究、学术交流、跨国合法经贸及网络安全测试使用。读者在使用过程中须严格遵守所在国家与地区的法律法规，严禁利用相关技术从事任何违法违规行为。

## 七、常见问题（FAQ）

### 代理客户端（dailikehuduan.cc）是一个什么样的网站？
代理客户端是专注于开源代理协议、多平台客户端配置教程、网络排障手册与机场中继服务可信度审计的客观技术文档知识库。本站致力于消除跨国中继行业信息不对称，杜绝虚假跑分与无节制软文推广。

### 本站对机场品牌的评测遵循什么方法学与证据标准？
全站统一执行《数据置信度五级规范》：严格区分 verified（多源核实事实）、measured（明确条件实测）、vendor（厂商单方宣称）、historical（历史归档记录）与 unverified（待核验项）。凡存在数据冲突或倒挂定价者，一律设立公开审计台账。

### 本站是否包含商业推广链接？如何确保评测公正性？
本站收录的部分外部品牌注册链接包含推广参数（统一标注 rel='nofollow sponsored noopener noreferrer'）。所获微薄佣金仅用于维持服务器运维与探针开销，所有推广链接绝不影响评测评分、不篡改测试数据，且凡有无退款霸王条款之品牌均在首屏给予强风险预警。

### 如果发现站内品牌数据有变动或错误，如何提交更正？
欢迎广大读者与品牌运营方提供可验证的书面凭据或最新后台测试截图。编辑团队将在 48 小时内核对并更新数据状态台账。
