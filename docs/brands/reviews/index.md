## 一、本站五级证据评测标准：为什么“文案长”不等于“实测靠谱”？

在中文互联网搜索「机场评测」或「机场测评」时，为什么读者看到的 90% 内容都是千篇一律的“全线 IEPL 专线、晚高峰 4K 秒开、完美解锁 ChatGPT 与 Netflix”？因为绝大多数推广博客直接把机场主提供的营销通稿（Vendor Claim）复制粘贴成了评测结论，既没有交代测试发生的日期与本地宽带运营商，也绝口不提优惠码排除条款和专属客户端锁定限制。

为了彻底切断「把厂商宣传当实测」的行业积弊，本站在构建 `brands.ts` 数据库与 31 篇独立品牌评测档案时，强制执行**五级证据链（Evidence Level）分类标准**。任何一句话只要进入评测表格，必须先明确其证据等级：

| 证据级别代码 | 中文定义 | 判定门槛与核查标准 | 站内典型样本举例 |

## 五、如何辨别虚假软文评测 vs 可验证实测（六步验真法）

当您在外部博客、Telegram 频道或论坛看到某篇“2026 最新机场测评排行榜”时，如何判断作者是真的买了订阅跑过测试，还是直接洗稿编造了数据？请对照以下 6 项硬指标逐条检验：

1. **查测速单位与宽带上下文（`MB/s` vs `Mbps` 换算陷阱）**
   网络带宽速率标准单位是 `Mbps`（兆比特每秒），而部分测速脚本（如 Miaoko / Speedtest 文件下载）显示的是 `MB/s`（兆字节每秒），两者存在 **8 倍换算关系**（`1 MB/s = 8 Mbps`）。例如 [灵动云](/brands/lingdong/) 的 `2026-07` 珠海联通 9Gbps 实测明确记录为 `20–80 MB/s`（折合 `160–640 Mbps`），而 `2026-10-19` 主表香港节点普遍记为 `477–548 Mbps`。如果一篇评测连 `MB/s` 和 `Mbps` 都混为一谈，或者贴出一张 `800 MB/s`（相当于万兆带宽跑满）却声称是家用百兆宽带测出的图，必属伪造。关于测速指标解读，详见 [延迟、带宽与吞吐量实测指南](/routes/latency/)。
2. **查是否将“视觉排版设计样图”混充实测**
   在本站原始资料整理过程中，附件 D《机场品牌图表样式.txt》曾包含一段带有“飞猫云 2026.6.1 测速与拓扑”字样的文本。经过交叉比对，该文本仅仅是用于演示页面卡片与拓扑图排版样式的 UI 设计占位符，并非真实测量报告。本站已在 [飞猫云档案](/brands/feimao/) 与 [品牌信息与近期变动](/brands/status/) 中将其显式剥离。正规评测必须隔离 UI 样图与真实日志。
3. **查是否披露“年付小包不打折”与“双优惠码冲突”**
   软文评测为了促成转化，只会大字标出“全场 8 折优惠码”，绝不会告诉您 **[光速云](/brands/guangsuyun/)** 的 99 元轻量版和 147 元永久版不打折，也不会提醒 **[Firefly](/brands/firefly/)**、**[灵猫网络](/brands/lingmao/)**、**[闪跃](/brands/shanyue/)** 的 8 折码全部排除了 85–96 元的年付引流包。
4. **查是否如实暴露“节点失败”与“YouTube 送中 / 落地偏移”**
   真实的物理网络不存在 100% 完美的节点。像 [灵动云](/brands/lingdong/) `2026-07` 实测那样，在指出“OpenAI 各地区基本全解锁”的同时，明确写明“HTTPS 延迟偏高、美国 01 整节点失败、TikTok 多失败、新加坡/台湾 YouTube 送中、台湾落地识别为西班牙 ES”，才符合真实抓包与解锁脚本（RegionRestrictionCheck）的客观规律。
5. **查客户端锁定边界（是否隐瞒“仅专属客户端”）**
   如果一篇评测向软路由或 Clash 用户推荐了 [飞猫云](/brands/feimao/)、[隐形人](/brands/yinxingren/)、[SOGO 云](/brands/sogo/) 或 [全球云](/brands/quanqiu/)，却只字不提它们不提供第三方通用订阅链接，说明作者根本没有登录过后台面板。
6. **在本地执行无偏见复测命令**
   购入月付测试包后，不要只看客户端面板的 ping 值（许多面板显示的是 ICMP 或本地到中转入口的延迟），建议在终端通过本地代理端口直接测试真实海外落地的 TLS 握手耗时与出口 IP 归属：

```powershell
# 通过本地 Clash Verge Rev / Mihomo 混合代理端口（默认 127.0.0.1:7897）实测访问 Cloudflare 与 OpenAI 的真实连接耗时
curl.exe -x http://127.0.0.1:7897 -o NUL -s -w "DNS解析: %{time_namelookup}s | TCP连接: %{time_connect}s | TLS握手: %{time_appconnect}s | 首字节TTFB: %{time_starttransfer}s | 总耗时: %{time_total}s`n" https://www.cloudflare.com/cdn-cgi/trace

# 查看当前节点实际落地的出口 IP、国家代码（loc）与 ASN 自治系统信息
curl.exe -x http://127.0.0.1:7897 -s https://www.cloudflare.com/cdn-cgi/trace | Select-String -Pattern "ip=|loc=|colo="
```

若发现 `time_appconnect`（TLS 握手）经常超过 `1.5s` 甚至超时，请结合 [节点超时与连接失败排查](/troubleshooting/timeout/) 以及 [系统时间同步与 TLS 握手修复](/guides/system-time-tls-fix/) 定位原因。

## 常见问题（FAQ）

### 1. 机场评测名录中的资料完整度“高（13家）”“中（7家）”“基础（11家）”是如何划分的？
完整度评级仅衡量可核验数据字段的覆盖密度，不代表对服务商稳定性的背书。“高”要求同时具备多档位套餐表、覆盖地区清单、协议或客户端模式说明及历史测速参考；“中”代表具备套餐框架但缺失测速或存在局部截图遮挡；“基础”代表原始资料仅有单一参考起步价与简短标签，缺失多档价目表、地区明细与测速。

### 2. 本站机场测评采用的“五级证据标签”分别代表什么含义？
五级证据包括：measured（具备明确测试环境与日期的实测归档，如灵动云2026-07珠海联通9Gbps记录）、vendor（品牌方宣传或面板标注参数）、historical（2026-10-19或2026-08-09历史清单汇总记录）、inferred（基于同源架构的审慎推断）以及unknown（原始资料未提及，待核实）。

### 3. 为什么飞猫云档案里没有采纳附件D《机场品牌图表样式.txt》中的2026.6.1测速与拓扑数据？
经站内审计核实，附件D中的“飞猫云2026.6.1测速与拓扑文本”属于前端排版与视觉图表样式设计示例，并非真实网络环境下采集的测量报告。为恪守零伪造原则，本站将其严格隔离，仅在飞猫云档案中收录2026-10-19主表历史测速参考。

### 4. 如何一眼识破市面上虚假的机场软文评测？
虚假软文评测通常具备四个特征：一是将年付折算月均价（如7元至9元每月）直接写成月付价格；二是隐瞒“仅专属客户端”限制，导致用户买完无法导入Clash或软路由；三是宣称“ChatGPT与Netflix永久100%稳定解锁”却不提落地IP风控波动；四是贴出无测试时间、无本地运营商说明、甚至混淆MB/s与Mbps单位的截图。

### 5. 2026-10-19批次的13家历史测速数据在横向参考时需要注意什么边界？
2026-10-19测速表原文明确标注为“非晚高峰历史汇总记录”，且未附带测速软件名称、单线程或多线程模式以及本地宽带运营商信息。因此该数据仅能反映各品牌在香港、台湾、新加坡、日本、美国五地的相对延迟梯队（如香港21–27ms、美国134–180ms），不能替代您本地宽带在20:00至23:00晚高峰的实测。

### 6. 为什么可信云（Kosing）在资料完整度为“基础”的情况下，仍在评测点评中获得正面透明度评价？
在众多同行纷纷使用“晚高峰零卡顿”“AI全解锁”等夸张宣传语时，可信云在2026-10-19原始资料中主动声明“AI与流媒体目前缺乏统一实测数据”，不做无证据承诺。这种克制且诚实的披露态度降低了用户的预期落差。

### 7. 31家品牌是否都已经拥有独立的深度评测详情页？
是的。截至 2026-11-23，全部 31 家去重品牌均已建立独立档案页（路径为 `/brands/<slug>/`），完整呈现各自的价格表、线路声明、AI 与流媒体解锁矩阵、历史测速表、风险提示与原始冲突记录，点击本名录中的任意品牌名称即可直达。
