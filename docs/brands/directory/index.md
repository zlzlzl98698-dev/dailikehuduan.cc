## 一、31 家去重机场品牌库构建与检索方法论

用户在搜寻机场品牌大全或进行机场品牌查询时，面临的最大障碍并非信息太少，而是评测站点普遍存在「同名马甲重复罗列」「将年付折算月均伪装成真实月付价」以及「隐藏专属客户端锁定限制」三大信息污染。如果缺乏一套标准化的结构化清洗规则，任何价格排序都会沦为低价引流套餐的诱导工具。

本站机场品牌库对原始 32 条收集记录执行了严格的去重、时间戳对齐与证据分级：首先将主表 `#8 Firefly` 与末尾扩展表 `Firefly 萤火虫` 合并为唯一标准档案 **[Firefly（萤火虫）](/brands/firefly/)**，从而将全库收敛为 **31 家独立去重品牌**；其次，将每一条价格、线路、解锁声明与测速记录强制拆分为 `measured`（实测归档）、`vendor`（品牌方资料）、`historical`（历史收集汇总）、`inferred`（合理推断）与 `unknown`（待核实）五个证据层级。

这一建库规则仅针对已纳入 `brands.ts` 的 31 家样本生效，且所有数据均对应明确的采集切片：其中 [光速云](/brands/guangsuyun/) 结合了 `2026-10-16` 专用资料与 `2026-08-19` 桌面归档截图；主表前 28 家品牌对应 `2026-10-19` 汇总快照；末尾扩展 3 家（[灵动云](/brands/lingdong/)、[浪网](/brands/langwang/)、[边缘节点 EdgeNova](/brands/edgenova/)）则明确标注为 `2026-08-09` 早期品牌库历史记录。当同一品牌在不同批次资料中出现前后矛盾时，数据库绝不擅自抹平，而是将冲突原样写入 `conflicts` 数组供用户检索核对。

在实际检索操作中，建议遵循「先锁客户端生态 → 再定付费周期口径 → 最后查证据完整度与优惠排除项」的三步检索法：
1. **第一步锁定客户端模式**：如果您需要在桌面端使用 [Clash Verge Rev](/clients/clash-verge-rev/)、[v2rayN](/clients/v2rayn/)，在 iOS 使用 [Shadowrocket](/clients/shadowrocket/)，或在路由器运行 [OpenClash](/clients/openclash/)，必须在检索器中优先筛选支持第三方通用订阅的品牌，直接剔除 8 家仅限封闭专属端的服务商。
2. **第二步区分月付试错与年付长持**：首次接触任何品牌，均应查看「真实月付门槛」而非「年付折算单价」，利用 15 元至 27 元的单月周期验证本地运营商晚高峰表现。
3. **第三步交叉核验冲突台账**：将初筛出的 2 至 3 家候选品牌加入同屏对比栏，随后跳转至 [品牌独立评测名录](/brands/reviews/) 与 [品牌信息与近期变动](/brands/status/) 检查是否存在链接异常或套餐缩水。

## 四、年付折算单价 vs 真实月付门槛：排序逻辑与成本陷阱拆解

在机场品牌查询与比价过程中，为什么按「最低月均价格」排序往往会买到并不适合自己的套餐？因为行业普遍采用「低价年付小包引流 + 正价月付主力盈利」的双轨定价模型。如果不把**年付折算月均（Monthly Equivalent）**与**真实月付门槛（True Monthly Entry）**拆开核算，用户极易掉入以下三类账单陷阱：

1. **首付现金流与沉没成本差异（3 倍至 5 倍首付差）**
   假设您看到某品牌标注「¥7/月起（50GB/月）」，实际上您无法掏出 7 元买一个月体验，而必须在结账页一次性支付 ¥84 至 ¥109 的年付账单。由于代理服务商普遍在风险条款中声明「虚拟特殊商品不支持退款」（如 [光速云](/brands/guangsuyun/) 资料原文明确提示），一旦买完年付发现该机场的出口 IP 被您常用的 AI 平台封锁，或本地移动宽带晚高峰连接其入口丢包严重，整笔年付资金就会变成沉没成本。相比之下，以 ¥18 至 ¥25 的真实月付档试错 30 天，最大试错风险被严格锁定在 25 元以内。
2. **优惠码「精准排除年付小包」规则**
   许多用户以为拿到 8 折优惠码就能在 85 元或 96 元的年付轻量版上再打 8 折（变成 68 元至 76 元/年）。然而核查 [套餐优惠与优惠码核验台账](/brands/coupons/) 可以看到，**[光速云](/brands/guangsuyun/)**（99 元轻量版与 147 元永久版不打折）、**[Firefly](/brands/firefly/)**（96 元年付版不适用 `firefly` 8 折码）、**[灵猫网络](/brands/lingmao/)**（85 元年付小包不适用 `lingmao` 8 折码）以及 **[闪跃](/brands/shanyue/)**（96 元年付版不适用 `shanyue` 8 折码）均明确将年付引流档排除在折扣范围之外。
3. **月流量额度断层（40GB–70GB vs 120GB–168GB）**
   年付轻量档的月均重置流量普遍卡在 `40GB`（无忧链接）、`45GB`（唯兔云、灵猫网络、EdgeNova）、`50GB`（飞猫云）至 `60GB–70GB`（光速云、暮光加速、星岛梦、一翻云等）。对于仅用于网页检索、Telegram 通讯与轻量 ChatGPT 文字对话的用户，60GB/月完全够用；但只要涉及观看 YouTube 4K 视频、Netflix 流媒体或频繁拉取 Docker 镜像与大型代码仓库，45GB–60GB 往往在半个月内就会耗尽。

因此，检索工作台的正确排序策略是：
- **新用户首月试水**：先在筛选器中选择真实月付区间（`¥10–¥20/月` 或 `> ¥20/月`），或者参考 [月付机场选购指南](/plans/monthly/) 与 [高性价比套餐核算](/plans/value/)，用单月账单跑满一个自然月。
- **轻度老用户续费或备用**：只有在确认某品牌的线路入口与您的本地宽带高度契合、或者仅需要一个低成本的轻度备用通道时，才切换至 `≤ ¥10/月（含年付折算）` 或勾选 `含一次性不限时包` 进行长周期锁定。关于超低价年付的带宽成本底线，请进一步阅读 [便宜机场与低价套餐边界](/plans/budget/)。

## 五、本地验证已选品牌的订阅协议与节点延迟实操

从上方机场品牌库筛选出支持「第三方通用订阅」或「自研+第三方订阅」的候选品牌并购入测试订阅后，如何不依赖厂商宣传语，直接在本地电脑核实其真实交付的节点协议、节点总数与 HTTP 握手延迟？您可以按以下标准化步骤在 Windows PowerShell 或 macOS/Linux 终端中完成独立验真：

```powershell
# 步骤 1：模拟 Clash Verge Rev 客户端 User-Agent 拉取订阅配置至本地临时文件（请替换为您实际的订阅地址）
$SubUrl = "https://example-sub-domain.com/api/v1/client/subscribe?token=YOUR_TOKEN"
$TempFile = "$env:TEMP\sub_audit.txt"
Invoke-WebRequest -Uri $SubUrl -UserAgent "clash-verge/v2.0.0" -OutFile $TempFile

# 步骤 2：检查返回文件是否为明文 YAML 还是 Base64 编码，并统计真实交付的协议类型分布
Select-String -Path $TempFile -Pattern "type:\s*(vless|trojan|ss|hysteria2|vmess|anytls)" -AllMatches |
  ForEach-Object { $_.Matches.Value } |
  Group-Object |
  Select-Object Name, Count

# 步骤 3：当 Clash Verge Rev / Mihomo 已启动并开启 External Controller (假设端口为 127.0.0.1:9097) 时，调用 RESTful API 实测节点统一 URL 延迟
curl.exe -s -G "http://127.0.0.1:9097/proxies" | Select-String -Pattern "name|type|delay"
```

如果步骤 1 拉取到的内容是一串无换行的 Base64 字符串（常见于未识别 `clash-verge` User-Agent 的旧面板），请参阅 [订阅链接格式详解与转换排障](/guides/subscription-formats-explained/) 或 [订阅无法更新故障排查](/troubleshooting/subscription/) 解码核对。若发现品牌宣传为 `VLESS` 专线但实际下发配置全部为老旧明文或高倍率节点，建议立即停止续费并参考 [线路倍率与真实流量计算](/routes/multipliers/) 评估实际损耗。

## 常见问题（FAQ）

### 1. 机场品牌库筛选器里的“年付折算单价”和“真实月付门槛”为何分开计算？
许多机场在宣传中以“约5.6元至9元每月”吸引用户点击，但该价格实际要求一次性支付67.2元至120元的年付账单，且通常不支持中途退款。若用户只想按月付试错，实际最低月付门槛往往在15元至30元之间。分开统计与排序能彻底消除低门槛错觉。

### 2. 为什么在机场品牌大全中筛选“第三方通用订阅”对路由器和桌面进阶用户更关键？
标记为“仅专属客户端”的品牌（共8家）只允许使用厂商封闭封装的App登录，不提供通用订阅URL，无法导入Clash Verge Rev、v2rayN、Shadowrocket或OpenClash软路由。只有选择“第三方通用订阅”或“自研+第三方订阅”的品牌，才能自定义分流策略组与多机场自动容灾。

### 3. 交互式同屏对比工作台最多支持同时勾选几个品牌？
交互对比栏支持同时勾选最多3个品牌进行同屏并列比对，可直观核查各品牌的最低真实月付、年付折算月均、一次性不限时包、客户端开放度、协议标注、覆盖地区数量、优惠码排除条款以及已知风险与冲突标记。

### 4. 为什么按“香港/日本/美国”地区筛选时，部分5.6元档和18元档品牌不会出现在结果中？
当某品牌的资料完整度为“基础”时（如大佬云、闪电鼠、极连云、光年梯等11家），2026-10-19原始快照未附带逐地区的节点明细表。检索器严格遵循零臆造原则，仅匹配有据可查的地区标签；未命中代表当前缺少公开地区证据，而非代表该品牌一定没有对应节点。

### 5. 筛选条件中的“仅看带历史测速”与“仅看含实测归档（Measured）”有什么本质区别？
“带历史测速”包含14家品牌，其中13家附带2026-10-19非晚高峰历史汇总记录（证据级别为historical，缺测试脚本与本地带宽说明）；而“含实测归档（Measured）”特指具备明确测试时间、网络环境与节点样本的记录，如灵动云在2026-07-20至07-21珠海联通9Gbps环境下的60节点实测摘要。

### 6. 默认排序“编辑精选”与按价格或完整度排序有什么差异？
默认“编辑精选”顺序综合了资料完整度、套餐档位丰富度以及站点推广合作权重（前11家带精选标记）。为确保检索客观性，建议用户在初筛时主动切换为“按真实月付升序”“按年付折算升序”或结合“第三方通用订阅”过滤后再做横向对比。

### 7. 在机场品牌查询结果中看到“链接格式异常”或“存在字段冲突”还能正常购买吗？
看到此类标记时应提高审慎度。链接格式异常（如云界线、榴莲云、环球梯缺少路由斜杠或前缀，或灵动云等2026-08-09历史入口）需先检验域名解析与面板渲染是否正常；字段冲突（如光速云59GB/69GB差异或隐形人双优惠码）则需在注册后以结算面板显示的实时账单为准。
