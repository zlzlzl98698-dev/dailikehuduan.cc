| **应用全称与别名** | `Shadowrocket`（中文社区常称“小火箭”） | 任何加了 `Pro`、`Free`、`Lite` 的同名应用均非正版 |

## 二、准备事项：正版安全获取与服务商格式核对

在手机上安装任何接管全机流量的工具之前，账号与来源安全永远排在第一位。

### 1. 守住外区 Apple ID 与防锁机三条红线

由于大陆区商店没有上架 Shadowrocket，搜索引擎上充斥着大量引流灰产。请务必死守以下安全规范（更多高仿骗局案例可查阅 [客户端下载安全与防钓鱼指南](/safety/security/)）：

1. **严禁在主力 iCloud 登录他人共享 Apple ID**：这是目前最常见也最具毁灭性的 iOS 勒索套路。只要你在 **设置 → 最顶部个人头像（iCloud）** 中输入了陌生共享账号，对方就能在网页端通过“查找我的 iPhone”把你的设备标记为丢失并远程锁死，随后索要高额解锁费。
2. **严禁安装来路不明的企业签名 IPA**：任何声称“不用外区账号、Safari 点击直接安装免越狱破解版”的网页，分发的都是企业证书重打包文件。这类 IPA 绕过了苹果商店沙盒审核，不仅随时掉签闪退，更可能在底层网络扩展中窃取你的订阅 Token、请求 Cookie 或支付凭据。
3. **正确安全获取姿势**：使用自己全新注册的个人邮箱，按苹果官方流程创建一个非大陆区（如美区、港区或日区）Apple ID，通过正规渠道购买对应区域的礼品卡充值买断。**日常主力备份照片和联系人依然保持大陆区账号登录在系统 iCloud 中**，仅在需要下载或更新小火箭时，打开 **App Store 商店 → 右上角头像 → 滑到底部退出登录**，临时切换外区账号下载完成后再切回日常商店账号即可。

### 2. 核对机场的 `clientMode` 与订阅类型

买好正版 Shadowrocket 后，登录你所使用的机场管理面板，确认其客户端交付方式是否支持第三方导入（站内核验标准见 [机场订阅与导入管理总览](/guides/subscription/)）：
- 如果服务商明确采用“自研+第三方订阅”或“第三方通用订阅”模式——例如同时提供自研端与第三方订阅且兼容 Shadowrocket 的 [光速云](/brands/guangsuyun/)，或主打 `Hysteria 2` / `VLESS-Reality` / `Shadowsocks` 通用订阅并适配小火箭的 [一翻云](/brands/yifan/)——即可直接在后台复制订阅 URL 导入。
- 如果遇到资料中标注 `clientMode` 尚属 `待核实` 的品牌（例如 [暮光加速](/brands/muguang/)），建议在购买长期套餐前先向客服确认或实测是否提供标准第三方订阅链接，避免错买成“仅专属客户端”品牌导致无法在小火箭中使用。

## 三、实际操作：添加订阅、配置分流与校准测速

打开安装在 iPhone 上的 Shadowrocket，首次安装建议先保持首页顶部的连接开关处于关闭状态，按以下四个步骤依次配置。

### 第一步：添加 `Subscribe` 订阅链接 vs 扫描二维码

1. **推荐方式——手动添加可更新订阅（Subscribe）**：
   - 在机场网页后台点击 **复制通用订阅 / Shadowrocket 订阅链接**（通常以 `https://` 开头）。
   - 打开 Shadowrocket，点击首页右上角的 **`+`** 号。
   - 在 **类型（Type）** 一栏点选 **`Subscribe`**（不要选成单节点协议类型）。
   - 将复制好的链接完整粘贴进 **URL** 输入框，检查前后没有多余空格；在 **备注（Remarks）** 填写易分辨的服务商名称。
   - 点击右上角 **完成（Done）**，小火箭会自动发起一次 HTTPS 请求并列出所有节点。
2. **快捷方式——网页一键导入或扫描二维码**：
   - 若机场页面提供“一键导入 Shadowrocket”按钮，在 Safari 中点击并允许跳转打开小火箭即可。
   - 如果需要从电脑屏幕扫码导入，点击小火箭首页左上角的 **扫一扫** 图标对准二维码。这里要注意区分：扫到 **订阅专用二维码** 会在首页建立可定期拉新的订阅组；而扫到 **单节点分享二维码**（如单条 `vless://...`）只会导入静态单节点，服务商日后变更节点 IP 时无法自动更新。

> **关于 Clash 链接的特别提醒**：如果你手头只有一条 Clash YAML 订阅地址，Shadowrocket 通常也能解析并提取出其中的节点列表，但**不会运行 Clash 订阅内置的 `proxy-groups` 策略组和 `rules` 分流脚本**。小火箭的流量分流完全由下一步的“全局路由 + 本地 `.conf` 配置”独立负责；若希望原样沿用桌面端 Clash 策略组，可评估 [Stash](/clients/stash/) 或免费开源的 [Karing](/clients/karing/)。

### 第二步：正确设置“全局路由（Global Routing）”模式

回到 Shadowrocket 首页，找到中部最关键的 **全局路由（Global Routing）** 栏，点进去会看到四个核心模式，新手最容易在这里选错导致国内 App 变慢：

| 全局路由模式 | 英文标签 | 底层调度行为 | 适用场景与常见误区警示 |
| --- | --- | --- | --- |
| **配置（日常必选）** | `Config` | 严格读取当前激活的 `.conf` 配置文件：国内域名/大陆 IP 直连，海外与AI等规则流量走代理节点 | **99% 日常使用场景首选**。国内微信/抖音/淘宝秒开且不消耗任何机场流量 |
| **代理** | `Proxy` | 忽略一切分流规则，强迫全机所有 App 请求全部经由当前选中的海外节点转发 | **仅用于临时排障**。长期开启会导致国内软件极慢、触发银行异地风控并成倍烧掉套餐流量 |
| **直连** | `Direct` | 所有连接全部绕过代理节点直接走本地宽带/蜂窝发出，但保留本地重写与规则记录 | 排查是不是节点故障、或临时只需使用本地规则调试时使用 |
| **场景** | `Scene` | 根据所处 Wi-Fi 名称（SSID）或蜂窝移动网络自动切换节点、配置或直连 | 适合家里已经挂了软路由、希望到家自动直连且出门自动开代理的用户 |

选好 **`配置（Config）`** 后，切换到软件底部导航栏第二个图标 **配置（Config）**，确认列表中至少有一套已激活（左侧带选中标记）的标准分流规则文件（如默认规则或社区维护的包含 `GEOIP,CN,DIRECT` 与 `FINAL,PROXY` 的标准 `.conf` 配置）。如果发现规则列表为空或此前误删了规则，可点击默认配置右侧菜单执行“更新”或“恢复默认配置”，确保国内流量拥有 `GEOIP,CN,DIRECT` 放行条目，且所有 `IP-CIDR` 规则末尾带有 `no-resolve` 避免触发无意义的本地 DNS 查询。

*(安全警告：切勿随意加载陌生来源、要求你在系统设置中信任“MitM HTTPS 解密根证书”的规则或脚本模块，普通分流完全无需安装任何根证书。)*

### 第三步：开启“打开时更新”，告别过期失效节点

机场的入口 IP 和中转域名会随网络波动定期轮换。如果不开启自动更新，过两周就会遇到“节点全灰、一个都连不上”的窘境：

1. 点击底部导航栏最右侧的 **设置（Settings）**。
2. 向下找到并进入 **订阅（Subscribe）** 子菜单。
3. 将 **打开时更新（Update on Open）** 开关拨至开启（绿色）。
4. 同页的 **后台自动更新（Auto Update in Background）** 建议一并开启，这样每次你切开小火箭界面或系统后台调度时，都会自动静默拉取最新节点列表，免去手工刷新。

### 第四步：把测速方法从 `PING` 校准为 `CONNECT` / HTTPS 测试

新手最困惑的现象莫过于“测了一遍延迟全都是绿色的 30ms，可一连上去网页就是转圈打不开”。原因就在测速方式：

- **默认 `PING` / TCP 测速的局限**：它只相当于向中转服务器端口敲一次门（TCP 握手），证明入口 IP 在线、端口没关；但它**完全不验证你的账号密码/UUID 是否正确，也不管后面的境外落地机器是否已经掉线**。
- **校准为 `CONNECT`（HTTPS 真实握手测速）**：
  1. 进入底部 **设置（Settings） → 测速方法（Latency Test Method）**。
  2. 将模式从 `PING` 或 `TCP` 切换为 **`CONNECT`**。
  3. 回到首页点击 **连通性测试**，小火箭会真实通过节点加密链路向测试地址发起完整 HTTPS/URL 探针请求。只有返回正常正数毫秒值（例如 `85ms`）的节点，才代表从手机到境外目标网站整条通路真正打通；凡是显示 `Timeout` 的节点可直接淘汰。

## 四、成功验证：授权 iOS VPN 权限与双路分流检验

完成上述所有配置后，进行以下四步上线验证，确保配置真正落到实处：

1. **授权建立系统 VPN 隧道**：在首页选中一条 `CONNECT` 测速返回绿色毫秒值的节点，拨动顶部主开关。首次启动时，iOS 系统会弹出 **“Shadowrocket 想要添加 VPN 配置”** 提示，点击 **允许（Allow）** 并验证 Face ID / 锁屏密码。
2. **确认状态栏 VPN 图标稳定**：等待约 1 至 2 秒，控制中心右上角（或屏幕顶部状态栏）出现 **`VPN`** 标志，且首页开关保持开启不回弹。
3. **验证国内直连与海外代理互不干扰**：
   - 打开手机 Safari 浏览器访问一个境外 IP 查询页或海外常用站点，确认能够秒开且显示的出口国家/地区与你所选节点一致。
   - 同时打开微信、淘宝或国内测速网页，确认图片与消息加载毫无卡顿，且在 Shadowrocket 底部 **数据（Data） → 统计 / 代理日志**（或规则命中记录）中，能看到国内域名明确走 `DIRECT`、海外域名走对应节点策略。
4. **验证“打开时更新”是否工作**：在确保当前节点畅通的情况下，回到首页长按你的订阅分组标题，手动测试一次更新，确认无红色报错弹窗。

## 五、常见错误定位与 iOS 专属排障清单

遇到订阅拉取报错、连接后断网或节点全超时，可先对照下表逐项核对，更多深度底层原理可参阅 [订阅更新失败排查](/troubleshooting/subscription/) 与 [客户端平台安全手册](/clients/platform/ios/)：

| 异常表现与报错 | 核心触发原因 | 精准排查与修复动作 |
| --- | --- | --- |
| **点击连接开关提示无法创建 VPN，或开关刚亮就弹回** | iOS“VPN 与设备管理”中存在其他冲突的加速器/VPN 配置，或首次权限被拒绝 | 进入手机 **设置 → 通用 → VPN 与设备管理**，删除多余旧代理描述文件后重连授权 |
| **添加或刷新订阅提示 `403`、`Timeout` 或无响应** | 本地运营商拦截/污染了订阅域名，或订阅链接复制时末尾缺失字符 | 若手头已有可用备用节点，先连上节点再长按订阅选 **通过代理更新**；核对官网套餐是否到期 |
| **全部节点 `CONNECT` 测速均显示 `Timeout`** | 1. 手机系统时间未自动同步导致 TLS/Reality 证书被拒；2. 本地旧订阅节点 IP 已更换 | 打开手机 **设置 → 通用 → 日期与时间** 开启 **自动设置**；随后更新一次订阅拉取最新入口 |
| **状态栏有 `VPN` 图标但 Safari 完全打不开任何网页** | 所选 `.conf` 规则损坏、节点本身已故障或路由误切为失效配置 | 临时将全局路由切为 **代理（Proxy）** 排除规则问题；若仍不通说明节点失效，换一条 `CONNECT` 绿灯节点 |
| **国内微信、支付宝或网银突然加载很慢** | 首页“全局路由”误选成了 **代理（Proxy）**，或当前 `.conf` 缺少 `GEOIP,CN,DIRECT` | 立刻将首页全局路由改回 **配置（Config）**，并更新或恢复默认分流配置文件 |
| **锁屏几分钟后顶部 `VPN` 图标自动消失断连** | 导入了体积过大的去广告文本规则，触发 iOS 对网络扩展进程（15–50MB）的内存强杀（OOM） | 精简掉动辄数万行的冗余文本规则与陌生模块，改用轻量标准 `.conf` 配置 |

## 常见问题（FAQ）

### 为什么不能借用网上的共享 Apple ID 或下载免越狱企业签名 IPA 来安装 Shadowrocket？

只要在 iPhone 系统“设置 → 顶部 iCloud”中登录了他人提供的共享 Apple ID，对方就能立刻通过“查找”功能远程将你的手机设为丢失模式并实施锁机勒索；即便仅在 App Store 内切换共享账号，也随时可能触发风控封禁导致无法更新。至于网页分发的陌生企业签名 IPA，本身绕过苹果商店审核，极易夹带隐私窃取模块或篡改流量。务必自己注册个人外区 Apple ID 并通过正规渠道购买正版。

### 在外区 App Store 搜索 Shadowrocket 时，怎么辨别正版和山寨收费软件？

正版应用全称为 Shadowrocket，开发者明确标注为 Shadow Launch Technology Limited，属于一次性买断制付费应用（美区长期常见标价约 USD 2.99，具体售价以各区域商店实时页面为准），购买按钮直接显示买断金额。凡是应用名故意加了 Pro/Lite/Plus 后缀、显示“免费获取”但内部引导每周高额自动续费订阅的，一律是仿冒山寨应用。

### Shadowrocket 添加订阅时，复制订阅 URL 和直接扫描二维码有什么区别？

本质上都是把服务商信息导入客户端，但适用场景不同。通过“右上角 + 号 → 类型 Subscribe”粘贴订阅链接，后续可以自动向服务器拉取新增节点与变更后的入口 IP；而用左上角扫一扫功能，如果扫到的是节点分享链接二维码，只会静态导入当前那几个单节点，服务商后续更换域名或端口时无法自动同步。只有当二维码内容本身是“订阅导入协议链接”时才会建立可自动更新的订阅条目。

### 全局路由里的“配置（Config）”“代理（Proxy）”“直连（Direct）”应该选哪一个？

日常使用必须选择“配置（Config）”。该模式会根据本地 .conf 分流规则自动判断国内流量直连、海外网站走节点，既能保证微信、支付宝和网银流畅不触发异地风控，又不会浪费机场流量。“代理（Proxy）”会强迫全部手机流量绕道海外节点，只适合临时排障；“直连（Direct）”则所有请求都不走代理服务器，仅用于本地网络调试。

### 为什么在 Shadowrocket 里测速明明显示几十毫秒，网页却还是打不开？

这是因为默认的 PING 测速模式只探测中转服务器端口是否开放（类似 Tcping），就算节点密码失效或后端已经宕机，只要入口端口通畅依然会显示低延迟绿灯。请进入底部“设置 → 测速方法”，将其切换为 CONNECT（或进行 HTTPS/URL 完整请求测试），只有完整握手并返回正数延迟毫秒值的节点才算真正可用。

### 每次节点更新后还是全部超时，或者点击连接开关后 iOS VPN 图标一闪就消失怎么办？

先检查手机“设置 → 通用 → 日期与时间”是否已开启“自动设置”，系统时间偏差会直接导致 TLS/Reality 握手被服务器拒绝；其次确认是否在“设置 → 订阅”中开启了“打开时更新”以防本地还存着过期节点；若系统 VPN 权限开关无法建立连接，进入 iPhone“设置 → 通用 → VPN 与设备管理”，清理冲突的其他代理或加速器描述文件后重新授权即可。
